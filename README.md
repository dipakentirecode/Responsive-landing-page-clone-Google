# SynthID Detector landing page

A responsive React recreation of the supplied Google About page screenshot. The phone and app interface are built from HTML and CSS; no stock or unrelated imagery is used. This is a visual clone, not a working media detector.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

## Stack

- React and JavaScript
- Vite
- CSS

## Responsive behavior

- Mobile navigation and compact phone layout: up to 767px
- Small mobile refinements: up to 380px
- Tablet/laptop sizing: 768px–1024px
- Desktop composition: 1025px and wider

The layout also uses fluid heading sizes and constrained content widths between breakpoints.
